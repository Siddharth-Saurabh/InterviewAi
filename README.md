# InterviewAi

AI-Powered Mock Interview Platform built with the MERN Stack, OpenRouter AI, Firebase Auth, and Razorpay.

## Features
- 🤖 **AI Mock Interviewer**: Real-time tailored technical, behavioral, and system design interviews powered by OpenRouter AI.
- 🎙️ **Voice & Speech Support**: Interactive speech-to-text voice answers and audio question narration.
- 📊 **Instant Comprehensive Feedback**: Real-time evaluation scorecards, strengths, improvement areas, and ideal benchmark answers.
- 💳 **Credit & Pricing System**: Integrated mock Razorpay payment flow and credit balance management.
- ⚡ **Modern Responsive UI**: Built with React, Vite, and glassmorphic aesthetics.
